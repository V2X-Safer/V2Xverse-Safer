## Oracle
对每次测试的质量进行评估，根据下列指标对质量进行评估，应当对指标设置优先级，使用综合的评价策略对轮次质量进行评价

- [ ] 任务: 到达目标点位
- [ ] 碰撞
- [ ] 交规: 交通信号 压线
- [ ] 驾驶质量: 急刹车 急加速 急转弯 长时停车
- [ ] 跟车间距

- [ ] 天气: 雨、云、风、雾、潮湿、水坑、太阳方位角和太阳高度
- [ ] 交通参与者: 类型 位置 数量 密度
