# ===== NOTE: Manual Installation Required =====
# The following packages need to be installed manually after creating the environment:
# 
# 1. SpConv (Sparse Convolution for Point Clouds):
#    pip install spconv-cu113==2.1.25
#    
# 2. PyTorch Geometric and related:
#    pip install torch-scatter torch-sparse torch-cluster torch-spline-conv torch-geometric -f https://data.pyg.org/whl/torch-1.10.0+cu113.html
#    
# 3. CARLA PythonAPI (if not using pip carla):
#    # Copy from CARLA installation or download wheel
#    
# 4. Custom OpenCOOD modules:
#    # Navigate to opencood directory and run:
#    # python setup.py develop
#    
# 5. Custom CoDriving modules:
#    # Navigate to codriving directory and run:
#    # python setup.py develop or pip install -e .

# ===== Installation Order Recommendations =====
# 1. Create conda environment: conda create -n v2xfuzz_v2xverse python=3.7
# 2. Install PyTorch with CUDA: conda install pytorch==1.10.2 torchvision==0.11.3 torchaudio==0.10.2 cudatoolkit=11.3 -c pytorch
# 3. Install this requirements file: pip install -r v2xfuzz_v2xverse_requirements.txt
# 4. Install manual packages (see NOTE section above)
# 5. Setup custom modules in development mode
